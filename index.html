How to Install VaultFlow on Your Phone (So It Never Loses Memory)

1. Inside Gemini (Cloud Sync)

While using this preview, your shifts and wallets are automatically synced to your cloud workspace and local browser database (`IndexedDB`).

2. Install as Home Screen App (PWA)

Host this `index.html` on free GitHub Pages or Netlify, open the link in Chrome on Android, tap Menu (⋮) → Add to Home screen / Install App. It runs fullscreen offline with permanent memory.

3. Convert to `.APK` in 1 Click

If you want a physical `.apk` installer file, paste your hosted link into PWABuilder.com or WebIntoApp.com to generate an Android `.apk` package in 60 seconds.
